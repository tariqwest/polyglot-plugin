Open Skills / Agent Skills

Open Skills is an open standard for portable SKILL.md folders that give AI agents on-demand, progressively disclosed expertise.

Open Skills operates in the AI agent extensibility segment. It is the closest thing to a cross-tool format for reusable task knowledge and is referenced by Claude Code, Codex, Devin, Gemini CLI, OpenCode, Kilo, Qwen, and others.

Open Skills is distinct from a plugin (which is a distributable bundle that may contain skills) and from MCP (which is a live tool protocol). Open Skills defines the instruction-pack format, not the bundle or the transport.

Open Skills: Canonical layout

A skill is a directory that contains, at minimum, a SKILL.md file. The directory name and the name frontmatter field must match. Supporting files live next to SKILL.md and are loaded only when referenced. 

.agents/skills/<skill-name>/
  SKILL.md              # metadata + instructions
  references/           # deep reference material (loaded on demand)
  scripts/              # helper scripts the skill may invoke
  assets/               # images, schemas, templates

Open Skills: Discovery roots

Harnesses that natively discover Open Skills folders typically scan these roots:

  • Project: .agents/skills/, .claude/skills/, .cursor/skills/, .gemini/skills/, .opencode/skills/
  • User: ~/.agents/skills/, ~/.claude/skills/, ~/.cursor/skills/
  • System / admin: varies by harness

Distinguishing Open Skills

Not a plugin
A plugin is a distributable bundle that may contain skills, agents, hooks, and MCP servers. Open Skills defines the skill folder format, not the bundle.
Not MCP
MCP exposes live tools over a protocol. Open Skills defines static, on-demand instruction packs.
Not AGENTS.md
AGENTS.md is an always-on instruction file. Open Skills uses progressive disclosure: metadata always, body only on invoke.

Open Skills: Related entities
