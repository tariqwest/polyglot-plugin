OKF plugin-type knowledgebase

The OKF plugin-type knowledgebase is a dated, living knowledgebase of what each AI agent harness calls plugins, skills, rules, extensions, and MCP, with official documentation links and polyglot bridge guidance.

The knowledgebase operates in the AI agent extensibility research segment. It is maintained as part of the polyglot-plugin skill and is the authoritative source for bridge decisions in generated packages.

The knowledgebase is distinct from a plugin package (it is reference data, not an installable unit) and from a marketplace (it is not a registry of installable plugins). It is a structured snapshot of harness extensibility surfaces, refreshed periodically.

OKF plugin-type knowledgebase: Tier structure

The knowledgebase classifies harnesses into three tiers:

Tier A — full official plugin/skills surfaces
Claude Code, Cursor, Codex, Copilot/VS Code, OpenCode, Gemini CLI, Devin/Windsurf, Warp. Authoritative for polyglot packaging.
Tier B — partial / MCP-first / instructions-first
Continue, Cline, Roo, Goose, Zed, Junie/PyCharm, Kiro, Aider, Kilo, Qwen, Grok Build, legacy OpenAI plugins. Have official extension surfaces but varying Open Skills support.
Tier C — guide-only / research-at-implement
Desktop/app shells, CLI/TUI agents, and suite utilities with no stable plugin/skill manifest surface. Polyglot default: use .agents/skills, AGENTS.md, and MCP; do not invent vendor manifests.

Distinguishing the OKF plugin-type knowledgebase

Not a plugin package
The knowledgebase is reference data used to generate packages. It is not itself installable.
Not a marketplace
It is not a registry of installable plugins. It is a structured snapshot of harness surfaces.
Not the Open Skills specification
It documents how harnesses discover Open Skills folders, but it is not the SKILL.md format specification.
