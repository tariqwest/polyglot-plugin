Model Context Protocol (MCP)

Model Context Protocol (MCP) is an open protocol that exposes live tools, resources, and prompts to AI agents over stdio or HTTP transports.

MCP operates in the AI agent tooling segment. It is supported by Claude Code, Claude Desktop, Cursor, Cline, Continue, Zed, Kilo, Goose, Junie, GitHub Copilot, VS Code, and others.

MCP is distinct from Open Skills (which defines static instruction packs) and from a plugin package (which bundles skills and optionally an MCP server). MCP is the transport layer for live tool execution, not the knowledge or bundle format.

Distinguishing Model Context Protocol

Not Open Skills
Open Skills defines static instruction packs. MCP exposes live, executable tools.
Not a plugin package
A plugin package may include an MCP server, but MCP is one transport layer within a package, not the package format itself.
Not an API gateway
MCP is agent-facing and tool-oriented, not a general-purpose HTTP API gateway.
