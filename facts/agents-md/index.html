AGENTS.md

AGENTS.md is an always-on instruction file convention used by AI coding agents to load project-level and user-level guidance at the start of every session.

AGENTS.md operates in the AI agent instructions segment. It is supported by OpenAI Codex, Kilo Code, Roo Code, Zed, Junie, and others. Some harnesses also read CLAUDE.md as a compatible equivalent.

AGENTS.md is distinct from Open Skills (which uses progressive disclosure and on-demand activation) and from MCP (which is a live tool protocol). AGENTS.md is always-on context, loaded before any user turn.

AGENTS.md: Hierarchy and discovery

Codex loads AGENTS.md hierarchically from ~/.codex through the project root down to the current working directory. Other harnesses follow similar root-and-subdir patterns. The file is plain Markdown with no required frontmatter.

Distinguishing AGENTS.md

Not Open Skills
Open Skills uses progressive disclosure (metadata always, body on invoke). AGENTS.md is always-on and fully loaded at session start.
Not CLAUDE.md
CLAUDE.md is the Claude Code-specific instruction file. AGENTS.md is the cross-agent convention. Some harnesses read both; AGENTS.md is preferred for cross-agent portability.
Not CONVENTIONS.md
CONVENTIONS.md is the Aider-specific convention, loaded via read: in .aider.conf.yml. AGENTS.md is broader.
Not MCP
MCP exposes live tools. AGENTS.md provides static, always-on text guidance.
